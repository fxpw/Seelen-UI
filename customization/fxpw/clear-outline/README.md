# Пробная тема прозрачности и обводки

Подготовлена для Seelen UI 2.8.10. Прозрачным становится фон панели, дока и меню приложений; прозрачность всего
контейнера через `opacity` не используется. Текст и иконки сохраняют видимость. Стандартная тема не редактируется,
контекстные меню не стилизуются.

Это первый вариант: визуальная проверка и подбор толщины обводки ещё нужны. Тема не меняет расположение панелей, состав
трея, данные датчиков или календарей. Силуэтная обводка растровых иконок может выглядеть иначе, чем обводка SVG.

Из корня репозитория, когда Seelen запущен:

```powershell
slu resource load theme .\customization\fxpw\clear-outline
```

Отключение этой темы:

```powershell
slu resource unload theme .\customization\fxpw\clear-outline
```

Проверка загрузчика ресурсов без применения темы:

```powershell
slu resource bundle theme .\customization\fxpw\clear-outline
```

В настройках темы доступны цвет текста, цвет и толщина обводки. При просмотре проверить рабочий стол, окно под панелью,
светлые обои, тёмные обои, масштабирование и фокус с клавиатуры. Всплывающие карточки, папки и прочие вложенные
поверхности могут потребовать отдельных правил после осмотра.
