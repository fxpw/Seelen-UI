# Состояние установленной версии, 2026-11-03

- Работает release 2.8.11 из `%LOCALAPPDATA%\fxpw-seelen\app`; ярлык «Seelen UI fxpw» находится в меню «Пуск».
- Проверка подписи и хешей ресурсов прошла при запуске. Отладочная копия остановлена, сервер разработки не нужен.
- Автозапуск: `\Seelen\Seelen UI Service`, `fxpw-SeelenSensors`, `fxpw-SeelenCpuSensors`. Все задания работают,
  запускаются при входе пользователя и имеют ограничение времени `PT0S`.
- Фоновый сборщик использует установленную копию Node и автоматически подключает датчики к новому PID интерфейса.
  Рабочая проверка готовности — `http://127.0.0.1:37074/ping`. Диагностика: `sensors/session-state.json` в локальной
  папке программы пользователя, а не в репозитории.
- Восстановление после остановки Node и после принудительного завершения собственного GUI проверено. Новый GUI получил
  показания автоматически. Полная перезагрузка Windows для проверки не выполнялась.
- Меню WSL и подсказки переведены на русский по явной просьбе пользователя. Последовательности трёх команд проверены
  через dry-run; действующие Linux-сессии при проверке не завершались. Меню открыто и проверено визуально.
- Увеличение начинается примерно за 88 пикселей до дока. Снимки покоя, приближения и наведения подтвердили промежуточный
  рост вне панели, затем полное увеличение. Прозрачная область пропускает клики.
- Прошли 15 тестов, проверка типов, Svelte, Deno, форматирование Rust и проверка diff. Последняя полная release-сборка
  заняла 8 минут 45 секунд: `.tools/release-proximity-ru-build.log`.
- Код сохраняется в ветке `feat/fxpw-desktop`. Персональные настройки, снимки, рабочие файлы датчиков и материалы
  подписи находятся вне Git. Порядок виджетов сохранён; календари и включение прозрачной темы остаются отдельными
  задачами.

Для повторной установки использовать `scripts/fxpw/install-release.ps1`. Он запускает постоянные процессы через
Планировщик и ожидает только завершения установочного процесса. Для проверки кода завершения GUI-утилиты службы
используется `Start-Process -Wait -PassThru`, а не `$LASTEXITCODE`.

Обновление плавности дока:

- Источник ступенчатого приближения — прежний опрос координат раз в 100 мс. Док получает снимки до 144 раз в секунду
  через свой WebSocket; остальные виджеты сохраняют прежнюю частоту общих событий. Очередь хранит только последние
  координаты. Пропущенные интервалы не догоняются серией событий; при блокировке сеанса опрос приостанавливается.
- Увеличение и смещение сглаживаются через `requestAnimationFrame` с учётом времени между кадрами. Старый CSS-переход на
  140 мс удалён: он задерживал реакцию на каждую новую координату. После завершения движения цикл останавливается.
- Проверка таймера Rust на этой Windows: 143,97 Гц за 288 интервалов. Это измерение опроса, а не фактического FPS
  WebView. Частота отрисовки следует доступным кадрам монитора и может снижаться под нагрузкой.
- Логи проверки/сборки: `.tools/hover-144-check.log`, `.tools/hover-144-types.log`, `.tools/hover-144-rust-tests.log`,
  `.tools/release-hover-144-build.log`.
- Прошли 17 JS-тестов и 6 Rust-тестов транспорта событий, проверка типов/Svelte/Deno, форматирование и diff. Release
  собран за 9 минут 53 секунды и установлен; PID 6916, `/ping` вернул 200, оба дока и обе панели Ready, подпись и хеши
  ресурсов проверены. Все три задания автозапуска Running; датчики подключены к новому GUI. Резервная копия:
  `%LOCALAPPDATA%\fxpw-seelen\backups\release-20261103T1950225539597Z`. После запуска обновился порядок незакреплённых
  работающих приложений на левом доке; закреплённые элементы и пользовательские виджеты сохранены. Общие настройки и
  профили верхней/нижней панели не изменены.

Локализация времени уведомлений:

- Вместо независимого английского форматирования Moment используется `Intl.RelativeTimeFormat` с языком из настроек
  Seelen. Формы «1 минуту назад», «2 минуты назад», «5 минут назад» и «9 минут назад» проверены; английская локаль
  продолжает работать. Проверка типов/Svelte/Deno прошла. Лог сборки: `.tools/release-notification-ru-build.log`.

Действия средней кнопкой мыши:

- СКМ по уведомлению использует ту же команду удаления, что и крестик, и не активирует уведомление.
- СКМ по миниатюре Alt+Tab вызывает существующее принудительное завершение процесса. Крестик по-прежнему закрывает окно
  обычным способом. Выбор переходит к оставшейся задаче, пропуская окна завершаемого процесса; при исчезновении
  последнего окна переключатель закрывается.
- Браузерная проверка настоящих Svelte-компонентов в отдельном headless Edge прошла: русское время, средняя/правая/
  левая кнопки, выбор команды завершения, переход к другому процессу и обычное закрытие крестиком. Нативные команды в
  этой проверке заменены заглушкой. Проверка типов/Svelte/Deno прошла. Лог итоговой сборки:
  `.tools/release-middle-click-build.log`; промежуточная сборка только с русским временем остановлена.
- Сравнение температур отложено по просьбе пользователя: OCCT показывает `CPU Die (average)`, текущий источник виджета —
  `Core (Tctl/Tdie)`. Источник не менялся; `CCDs Average (Tdie)` не приравнивается к `CPU Die (average)`.
