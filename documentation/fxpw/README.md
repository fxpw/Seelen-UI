# Рабочий стол fxpw на базе Seelen UI

Форк: https://github.com/fxpw/Seelen-UI. Локально: `D:\repos\fxpw\Seelen-UI`, ветка `feat/fxpw-desktop`.

## Требования пользователя

- Полностью прозрачные фон панели задач и меню приложений («Пуска»), с непрозрачными иконками и текстом.
- Приложения и кнопка запуска слева; системные значки и дополнительные индикаторы справа.
- Обводка текста и силуэтов иконок для читаемости на обоях.
- Индикаторы нагрузки CPU, GPU, RAM; температуры при наличии реальных показаний датчиков.
- События из всех трёх источников: Outlook / Microsoft 365, Google Calendar и Яндекс Календарь.
- Ближайшая встреча текстом на панели и, возможно, в нижней части меню приложений.
- Контекстные меню пока не изменять.

Под «Пуском» пользователь описывает и меню запуска, и нижнюю панель задач. В реализации это разные виджеты:
`@seelen/apps-menu`, `@seelen/weg`; верхняя информационная панель — `@seelen/fancy-toolbar`.

## Проверенное состояние, 2026-11-03

Официальный MSIX удалён по просьбе пользователя. Собственная release-версия 2.8.11 установлена в
`%LOCALAPPDATA%\fxpw-seelen\app`: `seelen-ui.exe`, `slu-service.exe`, `slu.exe`, `sluhk.dll`. Интерфейс встроен в
исполняемый файл; сервер разработки для запуска не требуется. Рабочее место — два монитора 2560 × 1440.

Ряд меню и индикаторов перенесён вниз; док приложений расположен над ним с небольшим зазором. Порядок виджетов
сохраняется отдельно для каждого монитора. Док увеличивает приложение под указателем до 150%; соседи увеличиваются
меньше и раздвигаются без перекрытий. Эффект отключён для сенсорного ввода, уменьшенного движения и переполненного дока.
Плеер справа увеличивается до 120%, с плавным откликом соседних значков. При клике положение фиксируется, а во время
перетаскивания увеличение снимается. Эффект плавно начинается при приближении курсора примерно на 88 пикселей к панели,
ещё до наведения. Используются глобальные координаты курсора, поэтому прозрачная область вокруг дока пропускает клики к
приложениям.

Температуры CPU/GPU подключены: [сборщик датчиков](../../customization/fxpw/widgets/temperatures/README.md). Авторизация
Outlook/Google/Яндекс пока не реализована. Прозрачная тема подготовлена отдельно и пока **не включена**.

Базовый коммит исходников — `2f9aaa321b49fc2ac58aaa9188a2a6678e41c947`.

## Сборка и запуск

Обычная версия для ежедневной работы:

```powershell
.\scripts\fxpw\build.ps1 -Release
.\scripts\fxpw\install-release.ps1
```

Установка копирует готовые программы в `%LOCALAPPDATA%\fxpw-seelen\app`, создаёт ярлык `Seelen UI fxpw` в меню «Пуск» и
настраивает запуск при входе в Windows. VS Code, npm и сервер разработки для работы не нужны; Node для датчиков лежит
внутри установленной копии. Служба запускает Seelen и восстанавливает его после сбоя; отдельное задание
`fxpw-SeelenSensors` следит за сборщиком температур и подключает его к новым экземплярам интерфейса. Проверка готовности
использует реальный адрес `http://127.0.0.1:37074/ping`. Диагностика фонового задания без секретов пишется в
`%LOCALAPPDATA%\fxpw-seelen\sensors\session-state.json`.

Release собирается с оптимизацией, без отладочных окон. Проверки подписи и хешей ресурсов сохраняются: локальный ключ
находится только в `%LOCALAPPDATA%\fxpw-seelen\signing`, вне Git и устанавливаемой программы. Обновления оригинального
Seelen отключены для этой сборки, чтобы они не заменили изменения форка. Ограничение времени работы заданий снято.

Выпадающее меню `WSL ▾` содержит запуск, перезапуск и выключение. Запуск открывает дистрибутив по умолчанию; перезапуск
выполняет `wsl --shutdown`, дожидается завершения и запускает дистрибутив заново. Выключение завершает WSL целиком.
Служебная команда выключения выполняется без окна терминала.

Для разработки:

```powershell
.\scripts\fxpw\build.ps1
.\scripts\fxpw\start.ps1 -Mode debug -Sensors
```

Первичная подготовка библиотек и зависимостей: `build.ps1 -Bootstrap`. Используется debug-сборка с `custom-protocol`;
`build.rs` отслеживает `dist`, чтобы текущий JS попадал в автономный исполняемый файл. Без `-Mode debug` скрипт запуска
предпочитает установленную обычную версию.

## Возврат к обычному рабочему столу

В настройках Seelen открыть главную страницу и воспользоваться действием выхода из приложения. Закрытие окна настроек
само приложение не завершает. Фоновая служба останавливается командой `target/debug/slu-service.exe stop`.

Перед переносом панелей настройки и раскладки сохраняются в `%LOCALAPPDATA%\fxpw-seelen\backups`.
